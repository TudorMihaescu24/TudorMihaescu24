I study Computer Science at the Technical University of Cluj-Napoca. My bachelor's thesis is a platform that analyzes chest X-rays with deep learning, so I spend most of my time on medical imaging and on the web apps around it. I like building full-stack apps (Spring Boot, Angular, Next.js) and small visual tools that show how an algorithm works.
